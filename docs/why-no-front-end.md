# Views without a front end

The database holds the register, revision content, approvals, reviews, improvements, readers and activity. Your coding agent runs the CLI and explains the returned records. HTML reports are read-only snapshots. Re-render them for fresh data and verify the current version before using a printed procedure.

A graphical process editor gives you drag-and-drop modelling and a visual canvas. A phone app can support field access and offline capture. This base provides neither, and it does not execute workflows or capture desktop activity. It provides controlled procedure records and review work for an operator comfortable asking an agent.

Enterprise DNA can build a web view, mobile capture, authenticated access or integrations around the database as a scoped customisation. Agree those requirements before replacing an operational system. The base is useful without them for process ownership, documented steps, review dates and internal paperwork.
